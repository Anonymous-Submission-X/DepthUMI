# DepthUMI

Anonymous research project page for the DepthUMI submission. The site is a
single static HTML file served from the repository root by GitHub Pages.

Before publishing a paper revision, replace `assets/DepthUMI.pdf` with the
final anonymous PDF and verify that its metadata and text contain no author or
institution identifiers. The image assets in `assets/media/` are rendered from
the corresponding figures in the manuscript.
